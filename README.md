# شاپرک رویداد — Shaparak Events

افزونه وردپرس برای مدیریت **رویدادهای گذشته و فعلی** با تقویم شمسی و مجموعه‌ای از
ویجت‌های قابل استفاده در **Elementor** (رایگان و پرو).

این افزونه یک صفحهٔ آماده ندارد؛ شما با ویجت‌ها، خودتان صفحه را در المنتور می‌چینید.
تیتر اجباری‌ای در کار نیست: ویجت‌های تک‌رویدادی اصلاً عنوان چاپ نمی‌کنند و هر ویجتِ
فهرستی هم کنترل عنوان خودش را دارد (به بخش «تایتل‌ها» نگاه کنید).

---

## نصب

1. پوشهٔ پلاگین را در `wp-content/plugins/event-plugin` کپی کنید (یا فایل‌های همین
   مخزن را در یک پوشهٔ دلخواه بگذارید).
2. افزونه را از پیشخوان وردپرس فعال کنید.
3. المنتور باید فعال باشد؛ با فعال شدن، دستهٔ **شاپرک · رویدادها** به کتابخانهٔ ویجت‌ها
   اضافه می‌شود.

> قالب‌های المنتور Pro (Theme Builder) به‌صورت خودکار «تکی رویداد» و «بایگانی رویداد»
> را برای نوع محتوای رویداد می‌بینند، چون نوع محتوا عمومی و REST است.

---

## ساختار داده

### نوع محتوا: رویداد (`shaparak_event`)

با متا باکس «جزئیات رویداد» پر می‌شود (همه تاریخ‌ها شمسی و ارقام فارسی یا انگلیسی):

| بخش | محتوا |
| --- | --- |
| زمان و مکان | تاریخ شروع/پایان، ساعت، مکان، شهر، نشانی، لینک نقشه، لینک خارجی، رویداد شاخص |
| برنامه زمانی | ردیف‌های تکرارشونده: عنوان روز / ساعت / عنوان برنامه / توضیح |
| جوایز | مبلغ جایزه + توضیح (رتبه‌ها خودکار ۱،۲،۳ می‌شوند) |
| داوران و منتورها | نام، سمت، تصویر |
| برندگان | عنوان طرح/تیم، توضیح، تصویر |
| متن و محورها | محورها (هر کدام در یک خط)، گزارش، دستاوردها، لینک PDF |
| گزارش و گالری | گالری تصاویر |

**وضعیت رویداد (جاری / در حال برگزاری / گذشته) کاملاً خودکار** از روی بازهٔ زمانی
محاسبه می‌شود؛ دستی قابل تنظیم نیست.

### تاکسونومی‌ها

| تاکسونومی | کلید | کاربرد |
| --- | --- | --- |
| دسته‌های رویداد | `event_category` | منبع محتوای ویجت‌های فهرست (کنترل «دسته‌بندی» در فهرست/نشست‌های هفته/گزارش‌ها) و آیتم‌های پنل فیلترها |
| استان‌ها | `event_province` | **۳۱ استان ایران** که با فعال شدن افزونه خودکار ساخته می‌شوند و از صفحهٔ ویرایش رویداد به هر رویداد اختصاص می‌یابند (ستون «استان» هم به فهرست مدیریت اضافه می‌شود) |

### تقویم شمسی

* هر رویدادی که ذخیره شود — با هر وضعیتی — در تقویم ماه مربوطه می‌افتد.
* رویدادهای چندروزه روی **همهٔ روزهای بازه** علامت می‌خورند.
* اگر تاریخ شمسی پر نشده باشد، از تاریخ انتشار پست به‌عنوان fallback استفاده می‌شود.
* روی روزها حلقهٔ نقاط کلیک‌خورده است که به صفحهٔ همان رویداد می‌رود.

## ویجت‌های المنتور (دسته «شاپرک · رویدادها»)

۲۱ ویجت؛ نام هر ردیف همان عنوانی است که در پنل المنتور می‌بینید:

| ویجت | کاربرد |
| --- | --- |
| **رویدادها (فهرست)** | کارت‌های شبکه‌ای یا ردیفی: رویدادهای گذشته، فعلی، پیش رو یا همه + فیلتر دسته‌بندی |
| **رویداد شاخص (کارت بالای صفحه)** | کارت شاخص با شمارش معکوس شمسی |
| **نشست‌های این هفته** | ردیف‌های فشردهٔ نشست‌های هفتهٔ جاری با بج روز/ماه |
| **شمارش معکوس شمسی** | روز/ساعت/دقیقه تا شروع یا پایان رویداد |
| **جزئیات رویداد** | تاریخ، ساعت، مکان و وضعیت رویدادِ صفحه |
| **تقویم رویدادها (شمسی)** | تقویم ماهانه شمسی با نقاط رویدادها |
| **هدر صفحه رویدادها** | عنوان و زیرعنوان صفحه، راهنما، جستجو و سوییچ نمایش فهرست/تقویم |
| **اطلاع‌رسانی پیامکی** | فرم شمارهٔ همراه با دو سوییچ «نشست‌های هفتگی» و «رویدادهای استان من» (ذخیره در سایت، بدون درگاه پیامک) |
| **بنر رویداد (هدر صفحه رویداد)** | بنر تمام‌عرض با کاور، تاریخ و مکان |
| **برنامه زمانی (تایم‌لاین)** | تب به ازای هر روز + خط زمانی با نقطه‌های سبز؛ آیتم در حال اجرا هایلایت می‌شود |
| **جوایز** | کارت‌های رتبه ۱،۲،۳ با شمارهٔ رتبه در دایره؛ بعد از پایان رویداد پنهان می‌شود |
| **داوران و منتورها** | آواتار + نام + سمت (بدون عکس، آواتار پیش‌فرض) |
| **برندگان** | کارت‌های برگزیده با نشان رتبه |
| **گالری تصاویر** | گرید تصاویر با افکت هاور و نمایش بزرگ با کلیک |
| **محل برگزاری** | نقشه + نشانی + دکمهٔ مسیریابی |
| **گزارش رویداد** | متن گزارش و دستاوردها |
| **دکمه دانلود PDF** | فقط دکمهٔ «دانلود گزارش کامل (PDF)» با گرادیان آبی — جدا از بقیهٔ گزارش |
| **فیلترها** | انتخاب استان (۳۱ استان) + همهٔ دسته‌بندی‌ها به‌صورت خودکار (بدون تیتر)؛ کارت‌های **همهٔ ویجت‌های صفحه** را فیلتر می‌کند |
| **محورهای رویداد** | چیپ‌های محور |
| **درباره رویداد** | فقط چیپ‌های محور (تیتر و توضیح حذف شده) |
| **گزارش‌ها و برندگان** | اسلایدر کارت‌های رویدادهای برگزارشده: کولاژ عکس، بج «برگزار شد» + تاریخ، خلاصهٔ آمار و لینک گزارش کامل |

**کنترل «رویداد».** ویجت‌های تک‌رویدادی (بنر، تایم‌لاین، جوایز، داوران، برندگان،
گالری، مکان، گزارش، دکمهٔ PDF، محورها، دربارهٔ رویداد) کنترل انتخاب **«رویداد»** دارند:
خالی = رویداد فعلیِ صفحه، یا هر رویداد منتشرشده از فهرست — بنابراین همان قالب را
می‌توانید برای رویداد گذشته هم استفاده کنید. «شمارش معکوس شمسی» و «رویداد شاخص» هم
انتخاب‌گر رویداد خودشان را دارند.

ویجت‌های فهرستی (رویدادها، نشست‌های این هفته، تقویم، هدر صفحه، اطلاع‌رسانی، گزارش‌ها و
برندگان، فیلترها) رویداد خاصی نمی‌گیرند و «جزئیات رویداد» همیشه رویدادِ صفحهٔ جاری را
نشان می‌دهد.

### دکمه‌ها

تنها دکمهٔ رویداد **«مشاهده رویداد»** است؛ دکمهٔ «افزودن به تقویم» وجود ندارد.
دکمه‌های دیگر فقط لینک خارجی‌اند (مسیریابی نقشه و دانلود گزارش PDF).

### تایتل‌ها

ویجت‌های تک‌رویدادی هیچ عنوانی چاپ نمی‌کنند — تیتر هر بخش را خودتان در المنتور می‌نویسید.
چند ویجتِ فهرستی اما کنترل **«عنوان بخش»** (یا «عنوان») دارند که اگر خالی باشد چاپ
نمی‌شود؛ پیش‌فرض بعضی‌ها متن آماده است و باید خالی‌اش کنید:

| ویجت | کنترل | پیش‌فرض |
| --- | --- | --- |
| رویدادها (فهرست) | عنوان بخش | خالی |
| نشست‌های این هفته | عنوان بخش | «این هفته · نشست‌ها» |
| تقویم رویدادها | عنوان بخش | «تقویم رویدادها» |
| گزارش‌ها و برندگان | عنوان بخش | «برگزارشده · گزارش‌ها و برندگان» |
| هدر صفحه رویدادها | عنوان | «رویدادها و نشست‌ها» |

## شورت‌کدها

```
[shaparak_events state="past" number="6" layout="grid" title="رویدادهای گذشته"]
[shaparak_event_featured]
[shaparak_events_week number="6"]
[shaparak_event_card id="123"]
[shaparak_event_countdown id="123" label="تا شروع رویداد"]
[shaparak_events_calendar month="1403-07"]
[shaparak_component name="hero" id="123"]
```

| شورت‌کد | آرگومان‌ها |
| --- | --- |
| `shaparak_events` | `state` = `past` · `current` · `upcoming` · `any` (پیش‌فرض `past`)، `number` (پیش‌فرض ۶)، `layout` = `grid` · `row`، `title` |
| `shaparak_events_week` | `number` (پیش‌فرض ۶) |
| `shaparak_event_featured` | — |
| `shaparak_event_card` | `id` |
| `shaparak_event_countdown` | `id` (بدون `id` = رویداد صفحه)، `label` |
| `shaparak_events_calendar` | `month` به شکل `1403-07` (خالی = ماه جاری) |
| `shaparak_component` | `name` = `hero` · `featured` · `card` · `compact`، `id` (خالی = رویداد صفحه)، `layout` |

این شورت‌کدها با یا بدون المنتور کار می‌کنند؛ بقیهٔ ویجت‌ها فقط در پنل المنتور موجودند.

## پوشه‌ها

```
event-plugin.php              نقطهٔ ورود و بارگذاری کلاس‌ها
includes/                     هسته: تقویم شمسی، نوع محتوا، متا، کوئری، قالب، شورت‌کدها، اسکریپت‌ها، اتصال المنتور
widgets/                      ۲۱ ویجت المنتور + کلاس پایهٔ مشترک
templates/                    مارک‌آپ کارت‌ها (مشترک بین ویجت و شورت‌کد) — با قالب فرزند قابل override در
                              wp-content/themes/your-theme/shaparak-events/
assets/css/events.css         استایل همهٔ کامپوننت‌ها (RTL، واکنش‌گرا)
assets/js/events.js           شمارش معکوس و امکانات نوار ابزار (دکمهٔ پاک کردن جستجو)، فیلتر صفحه
                              — فرم اطلاع‌رسانی سمت سرور ثبت می‌شود و به جاوااسکریپت نیاز ندارد
assets/ace/                   فایل‌های ویرایشگر Ace به‌صورت محلی، به‌جای cdn.jsdelivr.net
dist/event-plugin.zip         فایل زیپ نصب‌شدنی افزونه
design/                       اسکرین‌شات‌های مرجع فیگما (برای توسعه — در .gitignore)
tools/                        ابزارهای موقت دریافت طرح از فیگما (در .gitignore)
```

## تاریخ‌ها

همهٔ تاریخ‌ها شمسی و با **ارقام فارسی** نمایش داده می‌شوند؛ محاسبات با کلاس
`Shaparak_Jalali` (تبدیل میلادی ↔ هجری خورشیدی) انجام می‌شود، بدون وابستگی به
کتابخانهٔ خارجی.

تست رگرسیون تبدیل تاریخ با هر CLI از PHP اجرا می‌شود:

```
php tools/test-date.php     # ۳۷ بررسی: لنگر تاریخ‌ها، رفت‌وبرگشت timestamp، پذیرش فیلد تاریخ
```
